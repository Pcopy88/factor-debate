# 标准数据与试样验收

输入财报版本表和历史行情表，支持 Parquet／CSV。所有金额统一人民币元；股票代码字符串须保留前导零。正式股票代码接受 `000001.SZ`、`600000.SH` 或米筐 `.XSHE`、`.XSHG` 格式，仅沪深 A 股。

## 财报版本表

每行表示「股票 × 报告期 × 当时公开版本」。修订后追加一行，绝不能回写早期数据。

| 字段 | 口径 |
| --- | --- |
| symbol | 股票代码 |
| period | 报告期末日期，例如 2021-06-30 |
| announced_at | 该报告首次实际公开日期 |
| version_date | 该行数值版本实际公开日期；首发版本与 announced_at 相同 |
| report_kind | cumulative（年初累计）或 quarter（单季度），一行内流量口径须一致 |
| revenue | 营业收入，流量 |
| net_profit | 归属于母公司股东的净利润，流量 |
| cfo | 经营活动产生的现金流量净额，流量 |
| operating_cost | 营业成本，流量；不能用含税总支出代替 |
| capex | 购建固定资产、无形资产和其他长期资产支付的现金，正数流量 |
| total_assets | 期末总资产，存量 |
| total_equity | 期末归母股东权益，存量 |
| accounts_receivable | 期末应收账款，存量；不得混入应收票据而不记录口径 |
| total_liab | 期末负债合计，存量 |
| cash | 期末货币资金，存量 |

字段缺失用空值表示，不以 0 代替。累计转单季需要上一季同年度累计版本；不存在或上一季是混合口径时返回缺失。分母为零返回缺失；同比用上年同期绝对值作分母，亏损转盈利和低基数仍需解释。

财务日期不得早于报告期，版本日期不得早于首次公告日期。使用合并报表和统一归母口径。数据源只有最新修订值时，不能标为历史时点已验收。

## 历史行情与交易状态表

每行表示「股票 × 交易日」。保留停牌日的估值价格及交易许可，保留退市前历史，不从当前存续名单反推历史股票池。

| 字段 | 口径 |
| --- | --- |
| symbol, date | 股票代码、真实交易日期；不允许重复 |
| open, close | 未复权开盘／收盘价格，正数；停牌时提供可解释的估值沿用价格 |
| adj_factor | 总收益调整因子，使 open × adj_factor、close × adj_factor 可用于分红／拆股调整的经济收益 |
| amount | 当日成交额，人民币元，非负 |
| market_cap | 当日总市值，人民币元，正数 |
| industry | 当时适用的中文行业分类，采用统一分级；银行／证券／保险／金融标签会排除 |
| is_st | 当时是否 ST／*ST，0 或 1 |
| can_buy, can_sell | 当日开盘执行假设下是否可买／卖，0 或 1；综合停牌、涨跌停和实际交易限制 |
| list_date | 首次上市日期 |
| delist_date | 退市日期；未退市为空 |
| delist_cash | 可选：结算日每股现金回收金额，允许明确记录 0；其他日期为空 |

无退市结算依据时，不得随意填 0。持仓缺少估值或结算记录会使该实验失败，并显示原因。标签缺失数量在报告中保留，不能据此删掉退市股票。初始上市至少 730 个自然日、最近 60 条行情至少 20 条记录的平均成交额不少于 1000 万元。

供应商字段转换后的日期、单位、行业代码、累计口径和历史状态仍需抽样核对。真实交易日历必须来自市场；演示用普通工作日，不能代替交易所日历。原始数据需覆盖退市、历史 ST、停复牌与更正公告。

## 试样核对记录建议

| 项目 | 验收证据 |
| --- | --- |
| 首次披露与修订 | 同一股票同一报告期的原始公告及后续更正公告，各自 PDF 日期与数值 |
| 累计／单季 | 同一年的 Q1、半年报、Q3、年报逐项勾稽 |
| 股票池与行业 | 历史存续名单、行业变更记录，包含退市与 ST 个案 |
| 收益 | 已知分红、送转、退市个案的手工核算 |
| 成交许可 | 停牌及涨跌停日的开盘可交易状态 |
| 覆盖 | 完整开发／验证／最终区间，及必要预热数据 |
| 费用 | 供应商书面报价、账户权限、接口额度及续费条件 |

上传页面的「已验收」是你对上述核验的明确登记，自动检查只能发现结构和覆盖问题，不能证明供应商历史数值真实。

超过网页单文件 150 MB 的数据，可通过本机命令导入：

```powershell
.venv\Scripts\python.exe -m research.cli import-data ashare-v1 D:\data\financials.parquet D:\data\market.parquet --source "供应商、版本和转换口径说明" --pit-verified
```

此处的 `--pit-verified` 仅在完成抽样后使用。Tushare／米筐试样接口保留原表而不直接生成本标准数据，防止把供应商的最新表误当作历史时点表。
