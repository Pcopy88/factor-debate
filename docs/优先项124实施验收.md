### 恢复与复现

1. 在实证中途完成 18 条实验后暂停，停止并重启本项目后台，然后恢复任务。
2. 对比重启前后这 18 条实验的 ID、指纹、数值和原创建时刻，全部一致；最终 42 条记录没有重复指纹与分区组合。
3. 在新的计算实例中重算质量基线的完整验证区报告，数值和所有保存字段与原档案完全一致。
4. 核验冻结批次、评估代码和研究代码哈希；反序输入所有候选重做筛选，结果与冻结清单相同。
5. JSON 与 Markdown 导出均含失败、批判、回应、父子变化、相似性、筛选及实验绑定。
