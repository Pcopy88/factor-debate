# 多智能体因子挖掘系统

面向沪深非金融 A 股的本地基本面因子研究系统，以**多智能体辩论**为核心，将资料阅读、独立提案、交叉批判、公式改写与回测验证串联起来。用户通过中文网页设置研究任务、审核实验批次，并查看完整的研究过程。

## 项目介绍

### 多智能体如何协作

系统由两个研究 Agent、一个工程 Agent，以及固定的流程控制和评估程序组成：

| 角色 | 主要职责 |
| --- | --- |
| 价值／质量 Agent | 从估值、盈利质量与现金流出发提出假设，检查增长的真实性 |
| 成长／财务动量 Agent | 从经营改善、增长变化与财务趋势出发提出假设，检查静态指标遗漏的信息 |
| 工程 Agent | 核对因子公式和预期方向是否与批准的假设一致 |
| 流程控制器与评估程序 | 管理人工审核、任务状态和预算，执行统一的因子计算、回测与筛选 |

两个研究 Agent 先独立提出假设，再交换提案进行批判和修订。实验获批后，系统将开发区和验证区的回测反馈、相似因子证据交给研究 Agent，进行有限轮次的改写与重测。通过筛选的候选会被冻结，再进入最终测试和人工审核。

### 主要功能

- **多视角辩论**：支持双 Agent 辩论、双 Agent 独立提案和单 Agent 三种研究方式，记录提案、批判、修改依据及父子版本。
- **资料与数据管理**：管理论文、公开研报及其版本核验记录；导入财报版本和历史行情数据，按当时可见的信息计算因子。
- **统一实验评估**：使用受限财务公式和固定评估程序，检查预测能力、交易成本、稳定性及因子相似性。
- **人工审核与任务恢复**：在确认任务、批准实验批次、决定候选入库三个节点等待用户操作；支持暂停、继续和状态持久化。
- **研究档案**：查看实验反馈、失败记录和候选筛选理由，导出 Markdown 报告与 JSON 完整档案。最终测试结果与研究 Agent 的改写上下文隔离保存。

网页包含 **任务设置、资料库、辩论与版本、实验结果、因子库、数据与模型** 六个页面。

### 技术栈

| 部分 | 技术 |
| --- | --- |
| 后端服务 | Python 3.12、FastAPI、Uvicorn |
| 工作流 | LangGraph、独立后台工作进程 |
| 前端页面 | React、TypeScript、Vite |

## 本地启动

### 1. 准备环境

当前安装脚本和密钥保存功能面向 **Windows**。开始前请准备：

- **Python 3.12**：确保终端中的 `python` 指向该版本。
- **Node.js 22 或更高版本**：用于安装和构建前端。
- 首次安装依赖时可访问 Python 和 npm 软件包源的网络环境。

将仓库克隆或下载解压到本地，在包含 `README.md` 的项目根目录打开 PowerShell，检查版本：

```powershell
python --version
node --version
```

### 2. 安装依赖

双击根目录下的 **安装依赖.cmd**，或在 PowerShell 中执行：

```powershell
.\安装依赖.cmd
```

安装脚本会依次完成：

1. 创建项目内的 Python 虚拟环境 `.venv`。
2. 优先按照 `requirements.lock.txt` 安装 Python 依赖。
3. 下载项目内使用的 npm，保存在 `.tools/npm/`。
4. 按照 `frontend/package-lock.json` 安装前端依赖，并构建到 `frontend/dist/`。

安装完成后，日常启动无需重复安装。首次安装和构建过程中请等待终端显示 `Setup complete`。

### 3. 启动服务

双击 **启动研究室.cmd**，或执行：

```powershell
.\启动研究室.cmd
```

脚本会在后台启动网页服务和研究工作进程，并打开浏览器。默认地址：

| 用途 | 地址 |
| --- | --- |
| 中文网页 | http://127.0.0.1:8765 |
| API 文档 | http://127.0.0.1:8765/docs |
| 服务状态 | http://127.0.0.1:8765/api/health |

首次启动会初始化数据库并生成内置演示数据。网页右上角显示“研究引擎已连接”时，后台工作进程已就绪。

服务仅监听本机地址。关闭浏览器不会停止后台任务；项目提供 **停止研究室.cmd** 用于停止本机服务。任务状态和检查点默认保存在 `runtime/`。

### 4. 运行第一轮演示

演示模式使用**合成数据和内置脚本提案**，无需配置 API 密钥，也不会调用云端模型，适合先了解操作流程。

1. 打开“任务设置”，点击“新建研究”或“创建第一轮研究”。
2. 选择“演示模式”，填写研究名称和研究问题，创建任务。
3. 点击“审核研究”，在**环节 1**确认目标，选择“批准，继续研究”并记录决定。
4. 在“辩论与版本”查看提案、批判与修改；到达**环节 5**后审核并批准实验批次。
5. 在“实验结果”查看回测结果、实证反馈、版本变化和筛选依据。
6. 如有候选进入**环节 10**，查看报告后选择纳入观察、人工保留或淘汰；也可导出报告和完整档案。

需要人工决定时，流程会等待审批。若没有候选通过筛选，任务会记录原因并正常结束。

## 配置真实研究

完成演示后，可以按以下步骤配置真实数据和云端模型。

### 1. 保存模型密钥

双击 **配置密钥.cmd**，按提示输入凭据名称与密钥。也可指定凭据名称：

```powershell
.\.venv\Scripts\python.exe -m research.cli set-secret research-model
```

`research-model` 是自定义凭据名称，之后需在网页模型配置中填写相同名称。密钥输入不回显，并保存在 Windows 凭据管理器中；网页只填写凭据名称。

### 2. 添加模型配置

在“数据与模型”页面添加候选模型，填写：

- 显示名称、模型 ID 和 HTTPS API 基础地址。
- 接口协议：`responses` 或 `chat_completions`。
- 本机凭据名称，例如 `research-model`。
- 每百万输入／输出 Token 的人民币报价，用于计算费用和控制本批预算。

所选模型需支持 **JSON Schema 结构化输出**；输入、输出报价不能同时为零。可以先运行页面中的模型试评，检查接口、输出格式和任务遵循情况。

### 3. 导入研究数据

在“数据与模型”页面导入两张标准数据表：

- **财报版本表**：包含报告期、公告日期、版本日期及财务字段。
- **历史行情与交易状态表**：包含行情、行业、上市和退市日期、ST 状态及买卖许可等字段。

网页支持 CSV 和 Parquet，每个文件不超过 150 MB。字段、单位和历史时点核验要求见 [数据口径说明](docs/数据口径.md)。

也可以通过命令行导入 Parquet 文件，将示例路径替换为本机文件路径：

```powershell
.\.venv\Scripts\python.exe -m research.cli import-data ashare-v1 "D:\data\financials.parquet" "D:\data\market.parquet" --source "数据供应商、版本与转换说明" --pit-verified
```

`--pit-verified` 表示你已完成历史时点口径的人工核验，仅在核验完成后使用。每次导入新的数据版本请使用新的数据集编号。

### 4. 准备资料并创建任务

在“资料库”添加论文或研报的原文链接、正文、发布机构和具体版本日期，核验后记录依据。默认研究资料截止日为 **2022-12-31**，只有满足日期条件且已核验的资料才会进入研究上下文。

随后新建“真实研究”任务，选择已验收的数据集、模型配置，并设置大于零的本批模型费用上限。确认目标后，按与演示模式相同的人工审核流程推进研究。

### 可选服务

以下服务按需配置，不是启动演示的前提：

| 服务 | 本机凭据名称 | 用途 |
| --- | --- | --- |
| Tavily | `tavily` | 搜索论文与公开研报来源，找到的资料仍需核验 |
| Tushare | `tushare` | 获取少量原始财务数据进行试样 |
| 米筐 | `ricequant` | 通过可选 `rqdatac` SDK 获取财务试样 |

通过 `配置密钥.cmd` 保存对应凭据。使用米筐前还需安装 SDK：

```powershell
.\.venv\Scripts\python.exe -m pip install rqdatac
```

供应商试样保存的是原始表；正式研究数据仍需按 [数据口径说明](docs/数据口径.md) 转换、核验并导入。

## 开发启动

完成首次安装后，可以分别运行后端和前端开发服务。

终端一，在项目根目录启动后端及后台工作进程：

```powershell
.\.venv\Scripts\python.exe -m research.launcher
```

如果已经通过 `启动研究室.cmd` 启动服务，可继续使用该后端，无需再次启动。

终端二，在项目根目录执行以下命令，启动前端热更新：

```powershell
cd frontend
node ../.tools/npm/package/bin/npm-cli.js run dev -- --port 5173 --strictPort
```

开发页面地址为 **http://127.0.0.1:5173**，`/api` 请求会代理到 `http://127.0.0.1:8765`。使用固定的 5173 端口，以匹配后端允许的页面来源。

前端修改完成后，在 `frontend/` 目录重新构建：

```powershell
node ../.tools/npm/package/bin/npm-cli.js run build
```

在项目根目录运行自动化测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## 项目结构

```text
research/              后端接口、Agent、工作流、数据处理与回测评估
frontend/              React 中文网页与前端构建配置
scripts/               安装、启动、停止及依赖管理脚本
tests/                 数据、公式、审批、迭代与隔离机制测试
docs/                  数据口径与开发文档
requirements.txt       Python 依赖范围
requirements.lock.txt  Python 依赖版本快照
runtime/               本机生成的数据库、数据版本、检查点与日志
```

`.venv/`、`.tools/`、前端依赖和构建产物、`runtime/` 已列入 `.gitignore`，在本机安装或运行时生成。

## 启动问题排查

- **提示 Python 版本不符**：安装脚本要求 Python 3.12。检查 `python --version`，确认终端选中了正确的解释器。
- **提示找不到 Node.js**：安装 Node.js 后重新打开终端，确认 `node --version` 可以正常执行。
- **页面提示“网页尚未构建”**：先完成安装或前端构建，再重启后端服务。
- **网页打不开或启动失败**：确认 8765 端口未被其他程序占用，并查看 `runtime/server-error.log` 和 `runtime/server.log`。
- **页面可打开，但任务没有推进**：先查看任务是否正在等待人工审核，再检查右上角研究引擎状态和 `runtime/worker.log`。
- **模型提示未配置凭据**：检查网页中的凭据名称是否与 `配置密钥.cmd` 保存的名称一致。
